# 📌 FocusFlow - Student Task Management System

## 📖 Project Description
FocusFlow is a web-based application designed for students to manage academic tasks and assignments efficiently. It allows teachers to assign tasks and students to track, complete, and submit them.

---

## 🚀 Features
- Student Dashboard
- Assignment Feed
- Task Status (Missing / Pending / Submitted / Completed)
- API Integration
- Simple UI for tracking tasks

---

## 🛠 Technologies Used
- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB
- Tools: VS Code, MongoDB Compass

---

## 📂 Project Structure
- **frontend/**: React + Vite frontend application.
- **backend/**: Node.js + Express backend API.
- **[FocusFlow Documentation](FocusFlow_Documentation.md)**: Detailed project architecture.

---

## ⚙️ Installation & Running

### 1. Clone the Repository
```bash
git clone https://github.com/Arunkumar2010/focusflow.git
cd focusflow
```

### 2. Backend Setup
1. Navigate to `backend/`
2. Run `npm install`
3. Create a `.env` file based on provided templates.
4. Run `npm run dev`

### 3. Frontend Setup
1. Navigate to `frontend/`
2. Run `npm install`
3. Run `npm run dev`
