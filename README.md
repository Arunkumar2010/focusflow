# 🚀 FocusFlow

FocusFlow is a modern productivity platform that combines the power of:

- 📚 Google Classroom (Assignments & Submissions)
- 📊 Microsoft Planner (Task Management & Deadlines)
- ✅ To-Do Apps (Personal Productivity)
- 🎥 Google Meet (Live Classes)

> Built as a full workflow system — not just a UI.

---

## 🎯 Features

### 📌 Core Features
- 🧠 Task Management System
- 📢 Assignment Feed (Classroom-style)
- 📎 Submission System (Upload & Track)
- 👨‍🎓 Role-Based Access (Student / Teacher)
- 📊 Status Tracking (Missing / Submitted / Graded)
- 📅 Deadline Tracking (Planner-style)
- 📁 “Your Work” Panel
- 🎨 Premium Dark UI (Glassmorphism + Gradients)

---

## 🖥️ Tech Stack

### Frontend
- ⚛️ React.js
- 🎨 Custom CSS (No Tailwind)
- 🧠 useState (No Redux)

### Backend (Planned)
- 🐍 Django / 🌐 Node.js

### Future Integrations
- 🤖 AI Assistant (Google Gemini API)
